# 🌐 Nền tảng Phát triển Web (CSE391)

## 📖 Giới thiệu
Môn học **Nền tảng Phát triển Web (CSE391)** cung cấp các kiến thức cơ bản và hệ thống  
về quá trình phát triển một ứng dụng web hiện đại.

Môn học giúp sinh viên hiểu rõ cách các thành phần web hoạt động và tương tác với nhau,  
từ giao diện người dùng đến xử lý dữ liệu, làm nền tảng cho các môn học nâng cao  
về lập trình web và an toàn thông tin.

---

## 🎯 Mục tiêu môn học
Sau khi hoàn thành môn học, sinh viên có thể:

- ✅ Hiểu và sử dụng **HTML5 Semantic**, **CSS3** và **Responsive Design**
- ✅ Nắm vững **JavaScript ES6+**, thao tác với **DOM**
- ✅ Làm việc với **bất đồng bộ** (Promise, Async/Await)
- ✅ Xây dựng **Single Page Application (SPA)** với  
  **React / Vue.js / Angular**
- ✅ Kết nối và xử lý dữ liệu thông qua **RESTful API**
- ✅ Hoàn thiện một **dự án web thực tế** phục vụ học tập và portfolio

---

## 📚 Nội dung chính
- 🌍 Tổng quan về Web và phát triển ứng dụng web  
- 🧱 Kiến trúc Client – Server, HTTP/HTTPS  
- 🧩 HTML5 & CSS3 (cơ bản và nâng cao)  
- 🎨 Responsive Layout, CSS Frameworks  
- ⚙️ JavaScript Fundamentals & DOM  
- 🔄 Lập trình bất đồng bộ và làm việc với API  
- ⚛️ JavaScript Frameworks và kiến trúc SPA  

---

## 🗂️ Cấu trúc học tập
Nội dung môn học được tổ chức theo **từng tuần**, từ nền tảng đến nâng cao:

- 📘 Tuần 0: Tổng quan và định hướng công nghệ  
- 📗 Tuần 1–3: HTML5 & CSS (Core → Advanced)  
- 📙 Tuần 4: CSS Frameworks  
- 📕 Tuần 5–6: JavaScript cơ bản, DOM & Async  
- 📓 Tuần 7: JavaScript Frameworks  
- 🛠️ Các tuần sau: Thực hiện và hoàn thiện dự án học phần
